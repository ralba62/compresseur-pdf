Découvrir

Simple, rapide, et sans surprise

Une seule fenêtre, trois blocs : choisir vos PDF, régler le niveau de compression, lancer. Voilà l’essentiel.

Traitement par lots

Plusieurs fichiers, ou un dossier entier avec ses sous-dossiers : l’arborescence est reproduite à l’identique dans le dossier de sortie.

Fonctionne hors ligne

Pas d’envoi, pas de téléchargement à attendre : c’est rapide, même avec de gros scans. Aucune connexion n’est nécessaire.

Originaux préservés

Les fichiers compressés gardent exactement le même nom, dans un autre dossier. Vos documents d’origine ne sont jamais modifiés.

Quatre niveaux de compression

De « Léger », sans recompression des images, à « Maximum ». Les réglages sont clairs : vous savez ce que fait l’application.

Pas de plafond imposé

Aucune limite de taille ou de nombre de fichiers fixée par un service : seules les capacités de votre ordinateur comptent.

Un journal lisible

Pour chaque PDF : le poids avant, le poids après, le pourcentage gagné, et une explication si le gain est faible.

Confidentialité

Vos PDF ne quittent jamais votre ordinateur

Contrats, factures, bulletins de salaire, dossiers médicaux, copies d’élèves… Compresseur PDF traite tout sur votre machine. Aucune donnée n’est envoyée sur Internet, et aucun compte n’est nécessaire.

  • Aucun envoi : le document n’est jamais copié sur le serveur de quelqu’un d’autre.
  • Aucune conservation chez un tiers : il n’y a rien à supprimer, rien qui traîne.
  • Aucun compte à créer, aucune publicité.

Vérifiez-le vous-même. Coupez votre connexion Internet, puis lancez une compression : elle fonctionne exactement de la même façon. Le code source de l’application est, de plus, public sur GitHub.

Soyons honnêtes : ce que l’application ne fait pas.

Elle ne sait faire qu’une chose, compresser. Pas de fusion, de découpage, de conversion ni de reconnaissance de texte (OCR). Elle agit sur les images contenues dans le PDF (scans, photos) : un PDF de texte pur gagne peu. Les images en noir et blanc pur, en CMYK ou avec un masque sont laissées telles quelles, et les PDF protégés par un mot de passe d’ouverture ne sont pas traités. Un service en ligne reste pertinent pour un document peu sensible, ou pour ses autres outils.

Installation

Installer en deux minutes

À faire une seule fois. Au premier lancement, votre ordinateur peut afficher un avertissement de sécurité. Voici ce qu’il signifie, et comment continuer sans risque.

À propos des avertissements de sécurité

Ces avertissements sont normaux pour une application indépendante. Ils ne signifient pas qu’elle est dangereuse : ils signalent qu’elle n’a pas (encore) été validée par Apple ou Microsoft.

macOS

L’application n’est ni signée avec un certificat de développeur Apple, ni notarisée (un contrôle automatique d’Apple). La protection de macOS, appelée Gatekeeper, demande donc une confirmation au premier lancement.

Windows

L’exécutable n’est pas signé numériquement. Le filtre SmartScreen peut afficher « éditeur inconnu » tant que l’application n’a pas acquis de réputation auprès de Microsoft.

Votre part de vigilance

Téléchargez uniquement depuis le dépôt officiel GitHub. On autorise une seule application : il ne faut jamais désactiver les protections de votre ordinateur.

  1. Téléchargez la bonne version

    Version puce Apple ou version Intel, selon votre Mac (voir « Télécharger » ci-dessus).

    Mac · puce Apple Mac · Intel

  2. Décompressez et installez

    Double-cliquez sur le fichier .zip téléchargé : l’application Compresseur PDF apparaît. Glissez-la dans le dossier Applications.

  3. Premier lancement : confirmez l’ouverture

    macOS bloque l’ouverture la première fois. La méthode recommandée est celle des Réglages Système, qui est le chemin officiel prévu par Apple.

    Méthode recommandée : les Réglages Système sans commande

    1. Double-cliquez sur l’application. Un message apparaît : cliquez sur Terminé (pas sur « Placer à la corbeille »). L’application ne s’ouvre pas pour l’instant, c’est normal.

    2. Ouvrez le menu Pomme, puis Réglages Système, puis Confidentialité et sécurité. Descendez jusqu’à la rubrique Sécurité.

    3. Cliquez sur Ouvrir quand même. Votre mot de passe (ou Touch ID) peut vous être demandé, puis confirmez avec Ouvrir. L’application se lance, et le message ne reviendra plus.

    Le bouton « Ouvrir quand même » n’apparaît que peu de temps après la tentative d’ouverture : s’il manque, refaites l’étape 1, puis revenez dans les Réglages. Sur un macOS plus ancien (avant Sequoia), un clic droit sur l’application puis « Ouvrir » suffit.

    Solution de secours : le Terminal si la méthode ci-dessus échoue

    Cette commande retire le marqueur « téléchargé depuis Internet » (l’attribut de quarantaine) que macOS appose sur les fichiers téléchargés. Elle ne modifie rien d’autre dans l’application. À réserver à cette application, téléchargée depuis le dépôt officiel.

    1. Ouvrez le Terminal : appuyez sur Cmd + Espace, tapez « Terminal », puis Entrée.

    2. Copiez la ligne ci-dessous, collez-la dans la fenêtre du Terminal (Cmd + V), puis appuyez sur Entrée.

    xattr -cr "/Applications/Compresseur PDF.app"

    3. Ouvrez l’application comme d’habitude, par un double-clic.

    Si l’application n’est pas dans le dossier Applications : tapez xattr -cr (avec un espace à la fin), glissez l’application dans la fenêtre du Terminal, puis appuyez sur Entrée.

  4. C’est prêt

    Les fois suivantes, un simple double-clic suffit. Vous pouvez glisser l’icône dans le Dock pour l’avoir toujours sous la main.

  1. Téléchargez l’application

    Une seule version, pour Windows 10 et 11.

    Télécharger pour Windows

  2. Extrayez le dossier

    Faites un clic droit sur le fichier .zip, choisissez Extraire tout…, puis Extraire. Ouvrez le dossier Compresseur PDF obtenu.

  3. Lancez l’application

    Double-cliquez sur Compresseur PDF.exe. Ne le déplacez pas tout seul : il a besoin des fichiers qui sont dans le même dossier.

    Si une fenêtre bleue « Windows a protégé votre ordinateur » apparaît, cliquez sur Informations complémentaires.

    Un nouveau bouton apparaît : cliquez sur Exécuter quand même. L’application s’ouvre, et le message ne reviendra plus.

  4. Créez un raccourci (facultatif)

    Pour la retrouver facilement : clic droit sur Compresseur PDF.exe, puis Envoyer vers, puis Bureau (créer un raccourci). Sous Windows 11, cliquez d’abord sur « Afficher plus d’options ».

Les schémas sont simplifiés : l’aspect exact des fenêtres peut varier légèrement selon la version de macOS ou de Windows.

Utilisation

Trois blocs, de haut en bas

L’application tient en une seule fenêtre : choisir les PDF, régler les options, lancer la compression.

  1. Choisissez les PDF

    Ajouter des fichiers… : sélectionnez un ou plusieurs PDF (maintenez Maj ou Ctrl / Cmd pour en choisir plusieurs).

    Ajouter un dossier… : tous les PDF du dossier sont ajoutés. La case Inclure les sous-dossiers, cochée par défaut, permet de descendre dans les sous-dossiers.

    Pour corriger la liste, sélectionnez des lignes puis Retirer la sélection, ou videz tout avec Vider. Un même fichier n’est jamais ajouté deux fois.

  2. Réglez les options

    Compression : choisissez un niveau dans la liste. En cas de doute, gardez Moyen.

    Illustration indicative de l’intensité de la compression, pas une mesure du gain garanti : le résultat dépend de chaque PDF. À « Maximum », les images sont visiblement dégradées.

    Dossier de sortie : il est proposé automatiquement. Si vous avez ajouté un dossier, c’est un dossier voisin nommé « NomDuDossier_compressé ». Si vous avez ajouté des fichiers, c’est un dossier « PDF_compressés » à côté du premier fichier. Vous pouvez le changer avec Parcourir…

    Les fichiers compressés gardent le même nom et vos originaux ne sont jamais modifiés. L’application refuse d’écrire dans le dossier des fichiers sources.

  3. Lancez la compression

    Cliquez sur Lancer la compression. La barre de progression avance fichier après fichier, et le journal affiche une ligne par document : le poids avant, le poids après et le pourcentage gagné.

    À la fin, l’application propose d’ouvrir le dossier de sortie : vos PDF allégés vous y attendent.

Comprendre les messages du journal

aucune image trouvée dans ce PDFLe PDF ne contient que du texte et des dessins : il y a très peu à gagner. C’est normal.
déjà optimisé, copié tel quelLa compression n’aurait rien gagné. Le fichier est copié à l’identique : un PDF ne devient jamais plus gros.
✘ … fichier protégé par mot de passeCe PDF est verrouillé par un mot de passe d’ouverture : il n’est pas traité.

Nos conseils. Commencez par le niveau Moyen, puis ouvrez un des fichiers obtenus pour vérifier qu’il vous convient. S’il est encore trop lourd, essayez Fort ; s’il vous semble trop dégradé, reprenez Léger : vos originaux sont toujours intacts. Le gain est important sur les scans en haute résolution, faible sur les PDF de texte.

Questions fréquentes

Vous vous demandez peut-être…

Mes fichiers sont-ils envoyés sur Internet ?

Non. La compression se fait entièrement sur votre ordinateur, et l’application fonctionne sans connexion.

Pourquoi mon ordinateur affiche-t-il un avertissement ?

Parce que l’application n’a pas été validée par Apple (signature et notarisation) ni signée pour Windows : ce sont des démarches payantes réservées aux éditeurs qui s’y inscrivent. L’avertissement ne dit rien du contenu de l’application. Voir la section « Installation ».

L’application est-elle sûre ?

Son code source est public sur GitHub et peut être consulté par n’importe qui. Téléchargez-la uniquement depuis le dépôt officiel, et n’autorisez que cette application : il n’est jamais nécessaire de désactiver la protection de votre ordinateur.

Mes fichiers d’origine sont-ils modifiés ?

Jamais. Les versions compressées sont écrites dans un autre dossier, sous le même nom.

Le texte de mon PDF est-il abîmé ?

Non. Seules les images intégrées sont recompressées. Le texte et les dessins ne sont pas dégradés.

Pourquoi mon PDF n’a presque pas changé de taille ?

Soit il ne contient pas (ou peu) d’images, soit elles étaient déjà bien compressées, soit elles sont d’un type que l’application laisse intact (noir et blanc pur, CMYK, images avec masque). Le journal vous indique ce qui s’est passé.

Puis-je compresser un PDF protégé par un mot de passe ?

Si le PDF demande un mot de passe pour être ouvert, non : l’application l’indique dans le journal et passe au suivant.

Où retrouver mes fichiers compressés ?

Dans le dossier de sortie affiché dans le bloc « Options ». À la fin du traitement, l’application propose de l’ouvrir directement.

Puis-je remplacer l’original par la version compressée ?

Oui, mais à la main : copiez le fichier compressé à la place de l’original une fois que vous l’avez vérifié. L’application ne le fait jamais à votre place.

Prêt à alléger vos PDF ?

Téléchargez Compresseur PDF pour Mac ou Windows. Vos documents restent chez vous.
